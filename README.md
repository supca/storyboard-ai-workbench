# 分镜AI提示词工作台

一个功能强大的单页应用，帮助您高效管理和生成AI绘画分镜提示词。

## ✨ 功能特性

### 🎬 核心功能
- **分镜管理**：添加、删除、调整分镜镜头
- **提示词生成**：自动组合前缀、可替换内容和后缀生成完整提示词
- **批量处理**：一键为所有镜头生成完整提示词
- **图片管理**：支持上传和管理手绘分镜及AI生成图

### 🎨 视觉体验
- **三种主题**：白日模式、暗夜模式、灰调模式
- **低饱和度配色**：护眼的现代设计风格
- **悬停提示**：鼠标悬停显示功能说明
- **响应式布局**：自适应不同屏幕尺寸

### 📚 资源管理
- **角色库**：管理和快速插入角色设定
- **场景库**：管理和快速插入场景设定
- **提示词模板**：保存和应用常用提示词模板
- **平台列管理**：自定义AI生成平台列

### ⚙️ 高级功能
- **撤回功能**：支持最多10步操作撤回
- **镜头拖动**：自由调整镜头顺序
- **列宽行高调整**：Excel式的表格尺寸调整
- **API集成**：支持多个AI生成平台API配置
- **数据导出**：支持JSON、Excel、Markdown格式导出
- **故事板打包**：一键导出完整故事板（含图片）

### 🎯 便捷操作
- **时间轴视图**：底部时间轴快速预览和跳转
- **全屏预览**：全屏浏览所有镜头
- **对比功能**：对比两张图片的差异
- **键盘快捷键**：支持Ctrl+S保存、Ctrl+O加载等

### 使用方法
1. 下载 `storyboard_workbench_enhanced.html` 文件
2. 用浏览器直接打开该文件
3. 开始使用！

### 浏览器兼容性
- Chrome/Edge (推荐)
- Firefox
- Safari

## 📖 使用说明

### 基本流程
1. **添加镜头**：点击「添加新镜头」按钮
2. **填写提示词**：在「可替换提示词」列填写画面描述
3. **插入资源**：从左侧角色库/场景库快速插入设定
4. **生成提示词**：点击「生成」按钮组合完整提示词
5. **上传图片**：在对应列上传手绘分镜或AI生成图

### 主题切换
点击右上角的主题按钮切换：
- ☀️ 白日模式
- 🌙 暗夜模式
- 🌫️ 灰调模式

### 撤回操作
点击左侧工具栏顶部的「↩️ 撤回」按钮，最多可撤回10步。

### 调整镜头顺序
按住镜头行最左侧的「↕️」图标，上下拖动即可调整位置。

## 🔧 技术栈

- **纯前端**：HTML5 + CSS3 + JavaScript
- **无后端**：所有数据存储在浏览器LocalStorage
- **第三方库**：
  - JSZip - 用于打包下载
  - FileSaver.js - 文件保存
  - SheetJS (xlsx) - Excel导出
